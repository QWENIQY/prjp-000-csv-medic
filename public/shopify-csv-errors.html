Shopify CSV import errors: what each one means and how to fix it

Updated 17 November 2026 · By the CSV Medic team at QWENIQY

Short answer: most Shopify CSV import errors come from six things. These are a header row that doesn't match Shopify's column names, a file that isn't saved as UTF-8 with commas, quotes that Excel has mangled, variants with missing or duplicate option values, prices with currency symbols or blanks, and image links that aren't public https:// URLs. Find your exact error message below for the fix. Or upload your file to CSV Medic, which repairs most of these automatically and points out the rest.

Shopify only tells you that a line failed, and often in confusing terms ("Incorrect header check" has nothing to do with headers). This guide explains every product CSV import error in plain English. For each one we say whether CSV Medic fixes it automatically, flags it so you can fix it, or can't help, in which case we say what to do instead. Error wording is taken from Shopify's help centre.

Invalid CSV header: missing headers

Fixed automatically

What it means: the first row of your file doesn't match Shopify's column names, so Shopify can't find a column it needs (usually Title).

Common causes: columns called "Name", "Price" or "SKU" instead of Shopify's names. Other causes are a header that isn't on row 1, trailing spaces after the last header, or a file separated by semicolons (common when Excel is set to a European locale).

How to fix it: rename each column to Shopify's exact header and make sure the header row is the very first line. Save the file as comma-separated UTF-8. See our Shopify CSV template guide for every column name.

CSV Medic: recognises over 100 common alternative column names ("Name", "Description", "Price", "SKU", "Qty", "Image URL", "RRP" and more) and renames them to Shopify's headers. It also converts semicolon and tab-separated files to commas and adds a missing Handle column.

Illegal quoting on line

Fixed automatically

What it means: Shopify couldn't read a quoted cell on that line.

Common causes: the file isn't saved as UTF-8. Another cause is a double quote inside a cell (like 12" pizza stone) that isn't escaped as two double quotes (""). A third is curly “smart” quotes added by a spreadsheet.

How to fix it: re-save as CSV UTF-8. In a plain text editor, go to the flagged line and make sure each quote inside a cell is doubled, and that the cell itself is wrapped in straight quotes.

CSV Medic: reads the file however it was saved (UTF-8, UTF-16 or Windows/Excel encoding). It then writes every cell back out with correct, standard quoting, so this error can't happen in the fixed file.

Missing or stray quote on line

Fixed automatically

What it means: a cell opens with a quote but never closes it, so Shopify reads the rest of the file as one giant cell.

How to fix it: open the file in a text editor, go to the line Shopify names, and add the missing closing quote or remove the stray one.

CSV Medic: re-quotes every cell correctly. If the file ends inside an unclosed quote, it warns you to check the last row, because some data may be missing from the original.

How to fix it: save the file as UTF-8. Text that is already garbled has to be corrected by hand.

A "Choose column headings" window appears

Fixed automatically

What it means: Shopify didn't recognise some of your headers and is asking you to match them by hand.

CSV Medic: renames your columns to Shopify's headers, so the file imports without this step.

Ignored line #-## because handle `example` already exists

Flagged for you to fix

What it means: two different products in your file use the same handle. Shopify treats rows with the same handle as one product, so the second one is ignored.

How to fix it: give each product its own handle. Rows that really are variants of the same product should share a handle, but should leave Title blank on every row after the first.

CSV Medic: creates missing handles from titles and reformats invalid ones. It flags any handle that is shared by products with different titles, so you can decide whether they're variants or separate products.

Ignored line #-## because it did not contain product data

Partly fixed, rest flagged

What it means: the first row for a handle has no Title, so Shopify can't create the product.

How to fix it: put the Title (and description, vendor and tags) on the first row of each product.

CSV Medic: if the title is on a later row, it moves it up to the first row. If a product has no title at all, it flags it. It also fills in missing handles on variant and image rows so they stay attached to the right product.

Validation failed: options are not unique

Flagged for you to fix

What it means: two variants of the same product have exactly the same option values (for example two rows with Size = "Small"). Sometimes the only difference is an extra space.

How to fix it: sort by handle, find the duplicate pair, and either change one option value or delete the duplicate row.

CSV Medic: trims stray spaces from every option value, removes rows that are exact duplicates, and points to the exact pair of rows that still clash.

Validation failed: The variant 'Default Title' already exists

Partly fixed, rest flagged

What it means: a product has more than one variant row but no option values, so Shopify tries to create its default variant twice.

How to fix it: give every variant a real option name and value (like Size / Small). For products with only one variant, use Title / Default Title.

CSV Medic: sets Title / Default Title on single-variant products. It flags products that have several variant rows but no option values, which are often accidental duplicates.

Validation failed: price can't be blank

Flagged for you to fix

What it means: a variant row has no price.

How to fix it: fill in the price on every variant row, as a plain number like 19.99.

CSV Medic: flags every variant with a missing price. It also cleans the prices you do have: it removes £, $ and €, converts European decimals like "12,99" to "12.99", and removes thousand separators, so "1,299.00" becomes "1299.00".

Inventory policy is not included in the list

Fixed automatically

What it means: the inventory policy column ("Continue selling when out of stock") only accepts deny or continue, in lowercase.

CSV Medic: converts values like "Deny", "no", "FALSE" or "stop" to deny, and "yes", "TRUE" or "allow" to continue. It sets blank values on variant rows to deny, which is Shopify's default.

Inventory quantity can't be blank

Fixed automatically

What it means: a variant is set to be tracked by Shopify but has an empty quantity.

How to fix it: enter 0, or leave the Inventory tracker blank if you don't track stock.

CSV Medic: sets blank quantities on tracked variants to 0.

Inventory quantity is not a number

Fixed automatically

What it means: the quantity contains text, separators or decimals, such as "1,000", "10.0" or "In stock".

CSV Medic: converts "1,000" and "10.0" into whole numbers and flags text it can't safely convert.

Fulfillment service can't be blank

Fixed automatically

What it means: a variant has no fulfillment service. If you ship orders yourself, the value should be manual.

CSV Medic: sets blank fulfillment services on variant rows to manual and lowercases values like "Manual".

Validation failed: getaddrinfo: nodename nor servname provided, or not known

Fixed automatically

What it means: an image URL couldn't be resolved, almost always because it's missing https:// at the start or has a leading space.

CSV Medic: adds https:// to links like cdn.example.com/image.jpg and //cdn.example.com/image.jpg, trims spaces and encodes spaces inside URLs.

Validation failed: An error occurred while trying to download the image

Partly fixed, rest flagged

What it means: Shopify reached the URL but didn't get an image back. That happens with a share page instead of a direct image link, an expired or private link, a file path on your own computer, or a site that blocks hotlinking.

How to fix it: use a direct link to the image file that opens in a private browser window without logging in.

CSV Medic: converts Google Drive and Dropbox share links into direct image links. It flags local file paths like C:\Users\…\photo.jpg, which Shopify can never download. It can't detect expired or blocked links, so test any image that still fails in a private window.

Incorrect header check

Fix it yourself

What it means: despite the name, this is not about your CSV headers. The image on that line is damaged or isn't really the file type it claims to be.

How to fix it: clear the image URL on that line to confirm. Then re-save the image as a normal JPEG or PNG and host it somewhere else.

Validation failed: The uploaded image exceeds the 20 megapixel limit

Fix it yourself

What it means: the image is too large. Its width × height is over Shopify's limit.

How to fix it: resize the image (for example to 4000 × 4000 px or smaller), re-upload it and update the URL.

Not a valid product category

Fix it yourself

What it means: the Product category doesn't exactly match Shopify's Standard Product Taxonomy.

How to fix it: use the full category path (e.g. Home & Garden > Linens & Bedding > Bedding > Bed Sheets) or the category ID (e.g. hg-15-1-2). The easiest source is a product export from your own store. You can also leave the column blank and set categories in Shopify afterwards.

Validation failed: Value must be a valid product reference

Fix it yourself

What it means: a metafield points to a product that doesn't exist in your store yet.

How to fix it: import the products first without those metafield values. Then run a second import that overwrites the products and adds the references.

Daily variant creation limit reached, try again

Fix it yourself

What it means: stores with 500,000 or more variants (excluding Shopify Plus) can create up to 10,000 new variants per 24 hours through CSV imports.

How to fix it: split the file into batches of fewer than 10,000 new variants and import one batch per day.

Import job already in progress. Please wait until current one is finished

Fix it yourself

What it means: Shopify runs one import at a time. Wait for the email confirming the current import has finished, then upload again.

Silent problems Shopify won't warn you about

Some mistakes import "successfully" but quietly damage your catalogue. CSV Medic checks for these too:

  • Barcodes in scientific notation: Excel turns 5012345678900 into 5.01235E+12, permanently losing digits. Flagged
  • Compare-at prices that aren't higher than the price: the product never shows as on sale. Cleared automatically
  • Weights entered in kilograms in the grams column: "0.5" becomes 0 g, so shipping rates are wrong. Flagged
  • Excel's leading apostrophes and ".0" endings on SKUs and barcodes. Removed automatically
  • Duplicate SKUs, which confuse inventory and order tracking. Flagged
  • Duplicate and messy tags, such as "tops, mens , tops". Cleaned automatically
  • SEO titles over 70 characters and descriptions over 320, which get cut off in search results. Flagged
  • true/false columns written as yes/no/Y/1. Normalised automatically

Before you import: a 60-second checklist

  1. Saved as CSV UTF-8, comma-separated, under 15 MB.
  2. Row 1 is the header row and uses Shopify's exact column names.
  3. Every product's first row has a Title. Every row has the product's URL handle.
  4. Every variant has a price and a unique combination of option values.
  5. Prices are plain numbers: no £/$/€, no thousand separators.
  6. Image URLs are public, direct https:// links.
  7. You have a backup of your current products (Products → Export) before overwriting.

Frequently asked questions

How do I fix my CSV file for Shopify?

Make sure the file is saved as UTF-8 with commas between columns, and that the first row matches Shopify's column headers exactly. Every product needs a Title and a URL handle. Prices must be plain numbers without currency symbols, every variant needs unique option values, and image URLs must be public https:// links. CSV Medic checks and fixes all of these automatically: upload your file, review the changes and download a clean file.

Why does Shopify say "Invalid CSV header: missing headers"?

The first row of your file doesn't match Shopify's column names. Usually a column was renamed (for example "Name" instead of "Title"), the header isn't on row 1, there are trailing spaces, or the file uses semicolons instead of commas. Rename the columns to Shopify's exact headers and save as comma-separated UTF-8.

What does "Illegal quoting on line" mean in Shopify?

Shopify couldn't read a quoted cell on that line. It's usually caused by a file that isn't UTF-8, curly quotes inserted by a spreadsheet, or a double quote inside a cell that hasn't been escaped as two double quotes. Re-save as CSV UTF-8 and fix the quotes on the flagged line.

What does "Validation failed: options are not unique" mean?

Two variants of the same product have identical option values (for example two rows with Size = Small), sometimes differing only by an extra space. Each variant needs a unique combination of Option1, Option2 and Option3 values.
