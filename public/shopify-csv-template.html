Shopify product CSV template: every column explained

Updated 17 November 2026 · By the CSV Medic team at QWENIQY

Short answer: a Shopify product CSV has one header row followed by one row per variant or image. The only column you must have for new products is Title. Add URL handle to group variants and images under the same product. Save the file as UTF-8, comma-separated, with the header on row 1, using Shopify's exact column names.

The 5 formatting rules

  1. UTF-8 encoding. In Excel use File → Save As → CSV UTF-8 (Comma delimited). In Google Sheets use File → Download → Comma-separated values.
  2. Commas between columns, not semicolons or tabs.
  3. Header row first, with Shopify's exact column names and no blank rows above it.
  4. Plain values: prices without currency symbols (19.99), lowercase true/false, weights in whole grams.
  5. Under 15 MB. Split larger catalogues into several files.

Required columns

  • Adding new products: only Title is required. Add URL handle if the product has variants or more than one image.
  • Updating existing products: URL handle and Title.
  • Variant details (SKU, price, weight and so on): include Option1 name and Option1 value. If you leave the option columns out, Shopify deletes the existing variants and creates a single default variant.
  • Tracked inventory: when Inventory tracker is shopify, Continue selling when out of stock and Fulfillment service can't be blank.

How rows work: products, variants and images

Shopify groups rows by URL handle. All rows that share a handle belong to one product.

  • First row of a product: all product-level details (Title, Description, Vendor, Tags, Type, Status) plus the first variant and first image.
  • Each additional variant: a new row with the same URL handle and the variant's option values, SKU, price, inventory and so on. Leave Title, Description, Vendor and Tags blank.
  • Each additional image: a row with the URL handle plus Product image URL and Image position. An image can share a row with a variant.
  • Products with no variants: use Option1 name = Title and Option1 value = Default Title.

Your store may also export market-specific columns such as Price / International and Included / International. These only apply if you use Shopify Markets.

Limits to know

  • Up to 3 options per product and 250 images per product.
  • Up to 250 tags per product and 20 barcodes per variant.
  • SEO title up to 70 characters and SEO description up to 320.
  • Very large stores (500,000+ variants, excluding Shopify Plus) can create up to 10,000 new variants per day by CSV.

Older column names

Older Shopify exports and many supplier files use the previous template's names, such as Handle, Body (HTML), Variant SKU, Variant Price, Variant Grams, Variant Inventory Qty, Variant Inventory Policy and Image Src. Shopify still accepts these, but recommends the current names. CSV Medic understands both, as well as common non-Shopify names like "Name", "Qty" or "RRP".
